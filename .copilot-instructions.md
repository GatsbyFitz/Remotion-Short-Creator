# Remotion Composition Guidelines for Gatsby Fitzgerald Running Channel

## Brand Identity
- Channel Name: Gatsby Fitzgerald
- Theme: Running, motivation, fitness, athletic content
- Style: Clean, minimal, Apple-inspired aesthetic
- Animation Philosophy: Smooth, purposeful, elegant - nothing unnecessary

## Color Palette
- **ALWAYS** use colors from `/src/remotion/theme.ts` (BRAND_COLORS)
- Never hardcode color values - import and use theme constants
- Brand Colors:
  - Black: #000000 (primary text, backgrounds)
  - Pink: #FF37A1 (accent, highlights)
  - Yellow: #E1FF62 (accent, energy)
- Gradients: pink → yellow
- Text on light backgrounds: Use black (textPrimary)
- Text on dark backgrounds: Use white (textLight)
- Keep it minimal - don't overuse colors

## Animation Standards

### Timing
- Default composition duration: 150 frames (5 seconds at 30fps)
- Default FPS: 30
- Fade-in animations: 30 frames (0-30)
- Subtitle delays: Start at frame 20
- Use spring animations for organic, smooth movement

### Spring Configuration (Apple-inspired)
```typescript
spring({
  fps,
  frame,
  config: {
    damping: 200,  // Higher damping for smoother, less bouncy
    stiffness: 100, // Lower stiffness for elegant motion
    mass: 1,
  },
})
```

### Clean Animation Principles
- **Minimal & purposeful**: Every animation should have a reason
- **Smooth transitions**: No jarring movements
- **Subtle effects**: Less is more - avoid over-animation
- **Consistent timing**: Use easing curves like ease-in-out
- **White space**: Don't fill every pixel - embrace negative space

### Interpolation
- Use `extrapolateRight: "clamp"` for fade-ins/opacity
- Use `extrapolateRight: "extend"` for continuous animations (like gradients)

## Composition Structure

### Default Resolution
- Width: 1920
- Height: 1080
- Format: Landscape (horizontal video)

### Props
- Compositions do NOT need to be dynamic
- Do NOT add props unless specifically requested
- Use hardcoded values from theme (BRAND_COLORS, BRAND_FONTS)
- Keep components simple without prop schemas

### File Organization
- Create compositions in `/src/remotion/[CompositionName]/`
- Main component: `Main.tsx`
- Register in `/src/remotion/Root.tsx`

## Visual Style

### Typography (Apple-inspired)
- **Primary Font**: Baga (semibold) - Use for main titles and headlines
- **Secondary Font**: Le Havre Rounded (Light) - Use for subtitles and body text
- **Tertiary Font**: Pollen - Use for accents and special emphasis
- Load custom fonts from `/public/fonts/` directory
- Title size: 100-120px (Baga semibold)
- Subtitle size: 40px (Le Havre Rounded light)
- Minimal text shadows: Use sparingly, prefer clean flat text
- Letter spacing: Slightly increased for premium feel
- Hierarchy: Clear size differences between title/subtitle

### Backgrounds (Clean & Minimal)
- Prefer solid colors or subtle gradients
- If using gradients: gentle pink → yellow, slow rotation
- Motion elements: Minimal and subtle (not distracting)
- Clean geometric shapes over complex patterns
- Generous white/negative space
- Avoid clutter - focus on the content

### Motion Elements
- Running-themed: Use horizontal moving elements
- Opacity: 0.2 for subtle background elements
- Speed: Complete movement within 150 frames

## Code Quality
- Use TypeScript for all components
- Use semantic variable names (titleOpacity, channelY, etc.)
- Keep components clean and simple
- No prop schemas needed unless specifically requested

## Example Composition Registration
```typescript
<Composition
  id="CompositionName"
  component={CompositionComponent}
  durationInFrames={150}
  fps={30}
  width={1920}
  height={1080}
/>
```

## Do's and Don'ts

### Do:
✅ Import BRAND_COLORS and BRAND_FONTS from theme
✅ Use spring animations for natural movement
✅ Add smooth transitions between elements
✅ Layer content for visual depth
✅ Keep compositions simple without props

### Don't:
❌ Hardcode colors or fonts - always use theme
❌ Use jarring or sudden transitions
❌ Add props unless specifically requested
❌ Forget to register compositions in Root.tsx
❌ Over-complicate with unnecessary schemas
